# LOCAL AUTOPILOT — Live Beta

Portale indipendente per **Roma Ovest / Sud-Ovest — Notizie di quartiere**.

Copertura editoriale interna: Municipi XI, XII, XIII + Trastevere/Municipio I, con 41 quartieri e micro-zone iniziali. Il frontend privilegia utilità quotidiana, “Cosa cambia per te”, eventi e attività locali. Il back office mostra prima di tutto le eccezioni che richiedono intervento.

Monetizzazione V1: House Ads e struttura per pubblicità locale già predisposte. Amazon e AdSense restano disattivati finché non sono collegati gli account e, per AdSense, il consenso/CMP richiesto. Nessun auto-upgrade o billing è presente.
